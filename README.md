# Project Management Dashboard

A modern project management dashboard built with React.js and Tailwind CSS for organizing projects, tasks, and team activities.

## Features

- 📊 Project and task dashboard
- 📁 Project management
- ✅ Task tracking
- 👥 Team management interface
- ⚙️ Settings page
- 🔍 Project and task search
- 📱 Responsive UI
- 🎨 Modern dashboard design

## Tech Stack

- React.js
- JavaScript
- Tailwind CSS
- Vite
