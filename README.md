# Project Management Dashboard

A modern and responsive project management dashboard built with React and Vite. The application provides a clean interface for managing projects, tasks, and tracking overall project activity.

## 🚀 Live Demo

https://project-management-silk-pi.vercel.app/

## 📌 Features

- 📊 Project management dashboard
- 📁 View and manage projects
- ✅ Task management interface
- 📈 Project and task overview
- 🎯 Task status tracking
- 🖥️ Clean and responsive user interface
- ⚡ Fast development and production build with Vite
- 📱 Responsive design

## ⚙️ Installation & Setup

### Clone the repository

git clone https://github.com/yashwanth-gattu005/project-management.git

### Navigate to the project

cd project-management

### Install dependencies

npm install

### Start the development server

npm run dev

The application will be available at:

http://localhost:5173

## 🏗️ Build for Production

npm run build

To preview the production build:

npm run preview
